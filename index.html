Componentes

ButtonElemento interactivo que dispara una acción.InputCampo de texto de una sola línea para captura de datos del usuario.SwitchControl de encendido/apagado inmediato (on/off) para una única opción independiente.CheckboxControl de selección binaria dentro de un grupo de opciones, con cambio pendiente de confirmación (a diferencia de Switch, que aplica al instante).AlertMensaje persistente e inline (no flotante) que comunica el resultado de una acción o el estado de una sección de la página.ToastNotificación flotante y transitoria que confirma el resultado de una acción puntual del usuario.

Principios

  1. Una sola fuente de verdad los valores viven en Figma Variables. Todo lo demás (JSON, CSS, código) se genera o sincroniza a partir de eso.
  2. Jerarquía estricta primitivo → semántico → componente. Nunca al revés, nunca se saltea un nivel sin justificación documentada.
  3. Nombra por intención, no por apariencia . color.text.danger, no color.text.red.
  4. Todo token tiene descripción . Un valor sin descripción de propósito es información incompleta, tanto para una persona nueva en el equipo como para una IA.
  5. Nada se borra, se deprecia . Los tokens tienen contrato con el código que los consume; eliminarlos rompe cosas silenciosamente.
